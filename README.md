# Asistencia del personal

Página para registrar la asistencia del personal de las instituciones educativas del estado Táchira
leyendo el código QR del carnet. Funciona sin internet una vez abierta.

Cada institución la abre con su propio enlace (lo envía la coordinación). Esta página no contiene datos
personales: el nombre de la institución y su nómina viajan en el enlace y se guardan solo en el teléfono.
